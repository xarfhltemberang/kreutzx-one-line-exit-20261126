# The One-Line Exit — The Printer Won't Let Me Leave

A one-line resignation letter for the make.fun bounty
[u-kreutzx-the-one-line-exit-1dc652d1](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1).

The entry:

> I hereby resign — the office printer has jammed on this letter four times, and I refuse to work somewhere that won't even let me leave.

The joke: the resignation letter itself is the evidence. The printer jamming on the letter is the last straw — the office can't even process someone quitting, so quitting becomes the punchline. One line, one specific voice, no padding.

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, 135 characters, no trailing newline), exactly as the kit requires.
